# Step 05: Timeline (Base Instructions)

## Goal
Establish an unambiguous chronological record of character locations, actions, and object states across a critical event window so alibis and causal chains hold together without contradictions.

## Isolated Unit Scope
- **1 bounded event window:** Track the chronological beats immediately before, during, and immediately after the **First Disruption** across `C-01`, `C-02`, `C-03`, `C-04`, and the MacGuffin.
- **Length cap:** 200–300 words total (do not rely on stopwatch-style minute/second math; use sequential event phases and observable transitions).

## Fixed Inputs
- `1_harness/01_project.md`
- `1_harness/02_goals.md`
- `1_harness/03_style.md`
- `2_steps/05_timeline/context.md`

## Base Deliverable Shape
1. **Event Window Phases:** Clear sequential phases (Pre-Disruption, Blackout/Disruption, Immediate Aftermath).
2. **Character & Object State Tracking:** Where each tracked character (`C-01`–`C-04`) and the MacGuffin are at each phase, what each character is doing, and who observes whom.
3. **Alibi Contradiction:** The single observable discrepancy created during this window that fuels later investigation.
